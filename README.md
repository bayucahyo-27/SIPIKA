# SIPIKA
### Sistem Klasifikasi Tingkat Produksi Ikan Tangkapan di Maluku Utara Menggunakan Algoritma Decision Tree

## Tentang Proyek
SIPIKA merupakan sistem berbasis web yang dikembangkan untuk mengklasifikasikan tingkat produksi ikan tangkapan di Maluku Utara menggunakan algoritma Decision Tree.

## Teknologi
- HTML
- CSS
- JavaScript
- PHP
- MySQL
- Python
- Scikit-learn
- FastAPI

## Struktur Repository
- frontend/ : Implementasi tampilan website.
- backend/ : Pengembangan backend menggunakan PHP.
- database/ : Struktur dan pengelolaan database MySQL.
- ml-service/ : Implementasi algoritma Decision Tree.
- dokumentasi/ : Dokumentasi desain dan workflow sistem.
